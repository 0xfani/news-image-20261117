One picture of the world's news on Tuesday 17 November 2026: eight stories across
Europe, the Gulf, the United States, Asia, Latin America, Africa, Turkey and tech,
each with a pictogram, a short headline and one line of detail.

- `entry.png` is the picture (1024 x 1024 PNG).
- `make_image.py` draws it with Pillow (run once on the build machine).
- `main.py` is the entry program: it copies `entry.png` to the output folder.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
